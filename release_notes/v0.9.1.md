# Release Notes - v0.9.1

**Date:** 2026-09-14

## Overview

v0.9.1 is a small polish release.
Bulleted and numbered lists on page views are more compact, and wikitext lists with nested or mixed levels now produce valid HTML.

---

## Changed

### Tighter list spacing

- List items are closer together: about 25px apart at the default font size, down from 29px.
- RST lists and "loose" Markdown lists (items separated by blank lines) wrap each item in a paragraph, which used to push items about 37px apart; they now match other lists.
- Nested lists sit close to their parent item instead of adding a large gap above and below.
- All three formats (Markdown, RST, wikitext) now space lists identically.
  The table of contents and footnote lists keep their own styling.

---

## Fixed

### Nested wikitext lists

A nested list was emitted beside its parent item rather than inside it (`<li>Bananas</li><ul>...`), which is invalid HTML.
Lists now nest correctly, for example:

```
* Bananas
** Cavendish
*# a numbered step inside a bullet
```

Mixed prefixes such as `*#` and `#*` now work as they do in MediaWiki; previously the second character was shown as text.

---

## Upgrade Notes

No database schema changes, no new dependencies and no configuration changes.
`RENDERER_VERSION` is now 16, so each page re-renders once on its next view.

```bash
cd /opt/pywiki
sudo systemctl stop pywiki
sudo -u pywiki git pull
sudo systemctl start pywiki
```

CSS URLs include the version, so browsers pick up the new list styling without a hard refresh.
