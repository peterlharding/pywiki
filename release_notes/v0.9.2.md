# Release Notes - v0.9.2

**Date:** 2026-09-14

## Overview

v0.9.2 is a small layout fix release.
The page table on namespace pages gives its space to page titles instead of the selection checkboxes, and the navbar fits on phone-sized screens.

---

## Fixed

### Namespace page table

The checkbox column used to take 40% of the table width, because a site-wide style sizes every table's first column for a page title.
Titles and column headers were squeezed onto two lines as a result.

- The checkbox column is now only as wide as the checkbox, and the **Title** column gets the space.
- Format, Version, Last edited by and Updated no longer wrap.
- **Select all** is now the checkbox in the column header, lined up with the row checkboxes (it still shows the partial state when only some rows are selected).
  **Export selected** and the selection count stay above the table.
- Every checkbox has an accessible label for screen readers.
- On narrow screens the table scrolls sideways inside its own box instead of widening the whole page.

Other tables are unchanged.

### Navbar on phones

With a user logged in, the navbar links overflowed a 390px-wide screen and clipped the dark mode button on every page.
The smaller link size intended for small screens was being overridden by a more specific rule; it now applies, and the navbar fits down to 360px.

---

## Upgrade Notes

No database schema changes, no new dependencies and no configuration changes.

```bash
cd /opt/pywiki
sudo systemctl stop pywiki
sudo -u pywiki git pull
sudo systemctl start pywiki
```

CSS URLs include the version, so browsers pick up the changes without a hard refresh.
