# Release Notes - v0.9.3

**Date:** 2026-09-14

## Overview

v0.9.3 corrects the footer credit on every instance.

---

## Fixed

### Footer names the project

The footer said "Powered by" followed by the instance's `SITE_NAME`, so a wiki called "Expanse Wiki" read "Powered by Expanse Wiki".
It now always reads **Powered by pywiki**, followed by the version, and links to the project repository.

The site name is unchanged everywhere it identifies the wiki itself: the navbar logo, browser tab titles and the header of printable pages.

---

## Upgrade Notes

No database schema changes, no new dependencies and no configuration changes.

```bash
cd /opt/pywiki
sudo systemctl stop pywiki
sudo -u pywiki git pull
sudo systemctl start pywiki
```
