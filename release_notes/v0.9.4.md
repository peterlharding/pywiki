# Release Notes - v0.9.4

**Date:** 2026-09-15

## Overview

v0.9.4 fixes table layouts across the site.
The revision history page no longer spends almost half its width on the Compare radio buttons, and several other tables and admin pages are tidied up.

---

## Fixed

### Tables size their columns to their content

A site-wide style gave the first column of every table 40% of the table width.
That suited tables starting with a page title, but not others:

- **Revision history** - the two Compare radio columns took about 40% of the table and pushed comments onto two lines.
  They are now only as wide as the radio buttons, and each radio button has a label for screen readers.
- **Users** - short usernames took 40%, wrapping the "Display name" header and the Edit buttons.
- **Namespaces** - namespace names took 40%, leaving descriptions squeezed.

The rule has been removed, so columns are sized by their content.
Page-title columns (Recent changes, profile contributions, Site status) keep a minimum width so titles don't wrap, and label/value tables (user profile, Site status, Health check, Special pages, user edit) keep a consistent label column so stacked tables still line up.

The namespace page table fixed in v0.9.2 was a first symptom of the same rule.

### Admin pages

- **Health check** and **Site status** showed literal `---` lines between sections; they are gone (the section headings already have a divider).
- **Log review** said "last 1 records"; it now uses the singular for one record.

---

## Upgrade Notes

No database schema changes, no new dependencies and no configuration changes.

```bash
cd /opt/pywiki
sudo systemctl stop pywiki
sudo -u pywiki git pull
sudo systemctl start pywiki
```

CSS URLs include the version, so browsers pick up the changes without a hard refresh.
